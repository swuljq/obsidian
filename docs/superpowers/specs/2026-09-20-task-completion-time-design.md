# Obsidian 任务完成时间设计

## 目标

扩展 Schedule Countdown 插件，为整个知识库中的 Markdown 任务自动记录真实完成时间，同时保留现有倒计时功能。

## 行为

- 任务从 `- [ ]` 变为 `- [x]` 或 `- [X]` 时，在该行末尾写入 `✅ YYYY-MM-DD HH:mm`。
- 时间使用用户本地时区，精确到分钟。
- 任务从完成状态恢复为未完成时，删除行末由插件管理的完成时间。
- 再次勾选时写入新的当前时间。
- 功能应用于整个知识库中的所有 Markdown 任务，不要求任务包含倒计时标记。
- 插件启用时已经完成的旧任务不自动补写时间，避免把插件启用时间误当成真实完成时间。

## 数据格式

完成时间直接保存为任务行末的可见文本：

```markdown
- [x] 完成材料提交 ✅ 2026-09-20 14:35
```

该格式不依赖插件即可阅读和搜索。插件只删除行末严格匹配 `✅ YYYY-MM-DD HH:mm` 的后缀，不删除任务正文中其他位置的相似文字。

## 状态检测与写回

- 插件缓存已观察到的 Markdown 文件任务状态。
- 编辑器或阅读模式引发文件变化时，对比修改前后的对应任务行。
- 只有检测到未完成到完成的明确转换时才追加时间；只有检测到完成到未完成的转换时才删除时间。
- 插件自身写回使用防重入标记，避免重复处理和无限修改循环。
- 对普通文本修改、任务新增、任务删除和旧的已完成任务不写入当前时间。

## 异常与兼容

- 仅处理标准 Markdown 任务语法 `- [ ]`、`* [ ]`、`+ [ ]` 及其完成形式。
- 保留任务行原有空格、正文、倒计时标记和其他后缀。
- 文件读取或写入失败时不改动内容，并在控制台记录错误。
- 如果任务修改同时伴随复杂的跨行编辑，插件先更新状态缓存，不猜测完成时间。

## 验证

- 验证编辑模式和阅读模式中的勾选操作。
- 验证取消勾选会删除完成时间，重新勾选会写入新时间。
- 验证普通任务、带倒计时任务、不同列表符号和大写 `X`。
- 验证已有已完成任务不会被补写，插件自身写回不会产生重复时间。
- 运行日期逻辑测试、JavaScript 语法检查和插件入口加载检查。
