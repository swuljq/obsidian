# Mermaid 正文图表手动缩放

## 用户确认

用户同意在现有转换插件中增加每图独立的缩放按钮，保留全屏功能。只改变显示尺寸，不重写 Mermaid、不重新调用 API。

## 行为

- 右上角工具栏包含缩小、当前百分比、放大、重置及全屏按钮。
- 默认 100%，表示原有自适应显示；范围 20%～100%，步长 10%，到达边界时禁用相应按钮。
- 图表等比例缩小并居中，实际占用的文档高度同步缩小，不使用只改变视觉效果的 transform。
- 用 SVG 的 viewBox 宽度和可用正文宽度计算显示宽度，窗口变化时继续适配。无 viewBox 时使用初始实测宽度。
- 缩放状态按当前渲染容器独立保存在内存中，不持久化到笔记或插件配置；完整重渲染恢复默认。容器内仅替换 SVG 时更新工具栏绑定的图表。
- 鼠标悬停或键盘聚焦显示工具栏；触屏始终显示；打印隐藏工具栏。
- 全屏克隆清除正文内联缩放样式，继续按全屏视口适配。

## 生命周期与边界

复用现有 Mermaid DOM 监听，不重复创建工具栏。仅处理 Mermaid 容器的直接 SVG 子元素，忽略工具栏图标中的 SVG。卸载时移除工具栏、缩放属性和包装类，允许重新启用后正常操作。

不修改 API 请求或生成提示词，不修改主题和正文通用 CSS，不加入跨会话缩放存储、拖拽缩放或大于默认宽度的横向放大。

## 验证

保留 API 回归测试；在真实 Chromium 中使用 SVG 测试夹具验证尺寸及正文高度变化、居中、边界、独立状态、响应式布局、键盘可达性、全屏、重新渲染和卸载后重新启用。无需真实模型请求或 API Key。
