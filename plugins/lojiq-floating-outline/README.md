# lojiq Floating Outline

作者：lojiq。

在每个笔记面板左侧显示可调整宽度的简洁树状大纲，仅使用折叠箭头和缩进
表示层级，不绘制层级竖线。当前章节显示淡绿色圆角背景和绿色文字，不再使用
大圆点及右侧绿色标记。长标题自动换行并对齐首行文字，长目录可以独立滚动。

## 使用

- 支持阅读模式、实时预览和源码模式。
- 点击标题按源文件行号跳转；编辑模式会将光标定位到标题。
- 悬停提示统一使用 Obsidian 的无障碍标签提示，不叠加浏览器原生 `title` 提示。
- 点击跳转后保持对应标题高亮，不被跳转产生的近似滚动行号改回上一节；
  手动滚轮、触摸滚动、拖动正文滚动条或按滚动键后恢复自动跟随。
- 阅读模式优先根据正文标题的实际屏幕位置更新高亮，仅在标题尚未渲染时
  回退到滚动行号；同名标题通过出现次序和行号辅助区分。
- 有子标题的项目显示箭头，点击箭头折叠／展开；不改变正文标题的折叠状态。
- 当前章节位于已折叠分支时，高亮其可见的上级标题，不强制展开分支。
- 同一篇笔记内更新标题时尽量保留折叠状态；切换笔记或重启插件后默认展开。
- 切换笔记、修改标题时更新，不向 Markdown 文件插入任何内容。
- 大纲默认占用 240px，拖动右侧分隔线可在 160 至 480px 之间调整。
- 正文区域随大纲宽度缩放，保留你自己的字体、段落、图片和代码样式。
- 大纲显示时正文靠分隔线对齐，保留 24px 间距；不再在剩余区域内二次居中。
  仍保留“缩减栏宽”的最大行宽限制，隐藏大纲后恢复原来的居中方式。
- 宽度在所有笔记面板间共享并保存，重启后恢复；拖动中按 Escape 可取消。
- 双击分隔线恢复 240px；也可聚焦分隔线后用左右方向键、Home、End 调整。
- 至少保留 360px 正文区域；笔记面板窄于 520px 时自动隐藏大纲、恢复正文。
- 不依赖“缩减栏宽”设置；阅读模式和编辑模式都使用相同的分栏宽度。
- 命令面板执行“显示／隐藏笔记左侧大纲”可手动切换，状态自动保存。
- 不依赖 lojiqUI，不影响 Obsidian 内置的大纲侧栏。

## 修改外观

直接编辑本插件的 `styles.css`。当前章节的文字和背景由 `--lfo-accent`、
`--lfo-active-bg` 控制，浅深色分别适配。
字体使用 `--font-interface`，字号默认 13px，根级标题稍加粗；每层缩进由
`--lfo-indent` 控制，默认 14px。折叠箭头仅用于有子标题的条目。
目录与正文之间的距离由 `--lfo-content-gap` 控制，默认 24px。

插件通过笔记面板上的临时定位类和宽度变量调整阅读／编辑容器，不改写正文
内容元素的排版。隐藏、卸载和打印时撤销分栏，恢复原来的正文宽度。
阅读模式使用 Obsidian 标题缓存；未保存的编辑内容使用本地解析器识别常规
ATX / Setext 标题，忽略 YAML 头部、围栏代码和缩进代码中的伪标题。
复杂 Markdown（例如多行 HTML 注释、嵌套容器）在阅读模式以 Obsidian 缓存为准。

插件卸载时移除大纲、事件监听器、观察器、定时器和定位类。
