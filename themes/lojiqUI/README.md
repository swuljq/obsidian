# lojiqUI

作者：lojiq。

这是一个仅负责 Obsidian 软件界面的本地主题，参考 Baseline 4.1.0
（Alexis C / svnaxis）的简洁圆角界面重新整理，不依赖 Baseline 文件。

## 负责范围

- 窗口背景、侧边栏和功能区。
- 标签页、面板边框、分隔线和状态栏。
- 设置导航、弹窗、菜单和界面按钮。
- 浅色和深色界面。

## 不负责的内容

不包含笔记正文、标题、字体、代码块、代码行号、引用、列表、图片、表格、
语法高亮、笔记宽度、嵌入内容的排版规则。没有复制 Baseline 的配色方案、
插件适配、悬浮侧边栏和 Style Settings 设置面板。

现有 `typography`、`code-style`、`content-style`、`image-style`、
`list-hierarchy`、`better-table-style` 继续负责内容。
未被这些片段定义的内容使用 Obsidian 原生样式。
`code-title-fence` 插件仍独立负责渲染代码块的行号。

## 修改方式

直接编辑本目录的 `theme.css`：

- `body` 中的 `--ljq-ui-*` 控制圆角、边框、间距。
- `body.theme-light` 控制浅色界面颜色。
- `body.theme-dark` 控制深色界面颜色。
- 下方按窗口、标签页、侧栏、设置和菜单分区。

工作区采用 IDE 风格的“底层框架 + 嵌入式面板”，不使用整圈外框或阴影。
浅色框架 `--ljq-ui-frame: #e5e7eb`，侧栏面板 `--ljq-ui-sidebar: #f7f8fa`。
标签栏与内容区连成一个完整面板：标签栏只有上方两角、内容区只有下方两角
使用 `--ljq-ui-junction-radius: 10px`，接缝处保持平直，仅使用细分隔线。
因此完整面板的四个外角是圆角，内部不会出现两个独立圆角框。
框架底色从面板间隙和外角处露出，原生分隔手柄本身保持连续、不做圆角。
面板右侧、底部预留一个分隔带宽度，避免原生调整手柄覆盖圆角。
横竖分隔带使用 Obsidian 原生调整手柄，保留拖动行为；桌面端默认宽度
为 `--ljq-ui-divider-width: 6px`，浅深色分别通过 `--ljq-ui-divider` 和
`--ljq-ui-divider-hover` 设置正常及悬停颜色。移动端不修改分隔手柄。
`--ljq-ui-panel-radius` 仍用于设置界面的分组，与工作区交界圆角独立。

主题只定义私有的 `--ljq-ui-*` 全局变量，不替换正文使用的全局字体、
背景和颜色变量。软件界面表面使用私有颜色；笔记本身不设置背景。
不使用通配符重置，也不修改编辑器 DOM、侧边栏定位或点击行为。

在“设置 → 外观 → 主题”选择 `lojiqUI`，六个内容 CSS 片段保持启用。
原 `Baseline` 留在旁边用于比较；切回即可回退。
更新 Baseline 不会更新或覆盖这个独立目录。

本地文件检查不能代替 Obsidian 内部的实际显示验证；如修改后未立即生效，
切换一次主题或重新加载应用。
